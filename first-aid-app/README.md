# امدادگر — اپ PWA کمک‌های اولیه

دستیار «تصمیم‌گیری» کمک‌های اولیه برای **امدادگر آموزش‌دیده**. با چند سوال چک‌لیستی (علایم قابل مشاهده) سریع‌ترین مسیر اقدام را نشان می‌دهد؛ ممنوعیت‌ها، پرچم‌های قرمز و زمان تماس با ۱۱۵ در همه‌ی صفحه‌ها.

> این پروژه در زیر‌فولدر `first-aid-app/` از مخزن قرار دارد تا مستقل از اپ «دیده‌بان بازار» (ریشه‌ی مخزن) توسعه یابد و هم‌زمان با آپ‌ها/اسنپ‌شات‌های مخزن محفوظ بماند. کاملاً self-contained است و به‌آسانی می‌تواند به ریپازیتوری مستقل منتقل شود.

**امکانات کلیدی:**
- **کاملاً آفلاین**: PWA با Service Worker؛ بعد از نصب اولیه هیچ اینترنتی لازم نیست.
- **پایگاه دانش جدا از کد**: دیتا (JSON) مستقل از اپ آپدیت می‌شود — نیازی به نصب مجدد اپ نیست.
- **آپدیت دلتا + «آخرین نسخه سالم»**: فقط کیس‌های تغییریافته دانلود می‌شود؛ اگر آپدیت خراب باشد، دستگاه روی نسخه‌ی قبلی سالم می‌ماند.

## اجرای محلی

```bash
cd first-aid-app
python3 -m http.server 8080
# http://localhost:8080
```

تست‌ها:

```bash
cd first-aid-app
node test/run-tests.mjs
```

> توجه: PWA و IndexedDB فقط روی `http`/`https` واقعی (نه `file://`) کار می‌کنند.

## معماری

```
index.html + css/ + js/   ← پوسته‌ی اپ (پیش‌کشش در Service Worker)
kb/
  symptoms.json           ← استخر علائم مشترک (چک‌لیست‌ها)
  categories.json         ← ۸ دسته + علائم هر دسته برای «علت نامشخص»
  cases/*.json            ← هر کیس یک فایل مستقل (id, version, hash)
  manifest.json           ← نسخه + هاش (SHA-256) هر مورد — خروجی build-manifest
js/kb.js                  ← IndexedDB + دیف منیفست + اعتبارسنجی هاش
js/engine.js              ← تریاژ + امتیازدهی کیس‌ها (کاملاً آفلاین)
sw.js                     ← Shell: cache-first | KB: network-first با فالبک
```

**فلوی کار:** خانه → تریاژ سریع (۳ سوال: هوشیاری/تنفس/خونریزی) → دسته → کیس → چک‌لیست علائم → اقدامات + ممنوعیت‌ها + پرچم‌های قرمز + ۱۱۵. مسیر «علت را نمی‌دانم» هم دارد (امتیازدهی روی علائم).

## چطور پایگاه دانش را آپدیت کنیم

1. فایل کیس را ادیت کنید و `version` همان کیس را +۱ کنید (کیس جدید = فایل جدید).
2. ساخت منیفست (هر بار `kbVersion` را +۱ می‌کند و هاش‌ها را حساب می‌کند):

   ```bash
   node tools/build-manifest.mjs
   ```

3. تست بزنید و کامیت کنید:

   ```bash
   node test/run-tests.mjs
   git add kb && git commit -m "kb: ..." && git push
   ```

4. تمام. دستگاه‌ها هنگام آنلاین بودن منیفست را می‌کشند و **فقط موارد تغییریافته** را دانلود می‌کنند. در صفحه‌ی «پایگاه دانش» در اپ، نسخه و تاریخ همیشه دیده می‌شود.

**قاعده‌های ایمنی آپدیت:**
- هاش اشتباه = رد شدن آپدیت + ماندن روی آخرین نسخه‌ی سالم.
- کیسی که از منیفست حذف شود، از دستگاه هم پاک می‌شود (برای بازنشستگی اصولی بهتر است `version` را بالا ببرید و محتوا را «غیرفعال» کنید تا جایی که مطمئن شدید همه آپدیت خورده‌اند).

## منابع دستورالعمل (پایه‌ی دیتای فعلی)

| حوزه | منبع |
|---|---|
| احیا / خفگی / اوردوز اوپیوئید | **AHA 2025 Guidelines for CPR and ECC** (اکتبر ۲۰۲۵) — ERC 2025 فقط به‌عنوان cross-ref |
| ضربه‌ها/خونریزی | WHO Basic Emergency Trauma Care (BETC) |
| نیش مار | WHO Guidelines for the Management of Snakebites (2nd ed.) + استراتژی ۲۰۱۹ WHO |
| آنافیلاکسی | WAO Anaphylaxis Guidelines 2020 |
| بقیه | IFRC / Red Cross first-aid guidelines + fact sheetهای WHO |

> ⚠️ **مهم:** این محتوا نیاز به بازبینی و تأیید **کمیته‌ی پزشکی هلال احمر** دارد، به‌ویژه مواردی که با `nationalNote` علامت‌گذاری شده‌اند (نیش عقرب، نیش مار، مرکز سم‌شناسی ۱۹۰).
