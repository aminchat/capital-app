# 📊 دیده‌بان بازار — اپ مستقل با فیلترهای پیشرفته

اپ وب (PWA) فارسی که داده‌ی زنده‌ی بازار بورس ایران را **مستقیم از سرورهای خود TSETMC** می‌گیرد،
فیلترها را در صفحه‌ی خودش اعمال می‌کند و نتیجه را در جدول خودش نشان می‌دهد — **بدون باز شدن سایت TSETMC**.

- منبع داده: `old.tsetmc.com/tsev2/data/MarketWatchInit.aspx` (عکس کامل بازار + عرضه/تقاضا) و
  `ClientTypeAll.aspx` (تفکیک حقیقی/حقوقی برای فیلترهای پول هوشمند).
- فرمت فید و همه‌ی محاسبات مشتق (درصد تغییر، P/E و…) دقیقاً از موتور خود صفحه‌ی دیده‌بان سایت برداشت شده است.
- اگر مرورگر اجازه‌ی دریافت مستقیم ندهد (CORS)، به‌ترتیب پروکسی‌های CORS عمومی
  (corsproxy.io → allorigins → codetabs) امتحان می‌شوند و روش سالم در مرورگر ذخیره می‌شود.

## فیلترها

**ویژه (۶):** 🧠 پول هوشمند (خرید حقیقی سنگین) · 🏛 ورود پول حقوقی · 💎 جا مانده از بازار (ارزنده) ·
🤫 تجمع بی‌سروصدا · ⚖️ فشار خرید سرصفحه · 🚨 هشدار توزیع — همه با آستانه‌های نسبی (درصد/ضریب) قابل تنظیم.

**پایه (۱۲):** حذف بی‌معامله، حداقل قیمت/درصد/حجم/ارزش، ضریب حجم مبنا، حذف اوراق و مشتقات، حذف تسهیلات،
حذف انرژی، حداکثر P/E، جستجو، سیاهه.

## اجرای محلی

```bash
cd market-app
python3 -m http.server 8080
# http://localhost:8080
```

## تست‌ها

```bash
node test/run-tests.mjs   # 47/47 — پارسر فید + فیلترها + قالب‌بندی
```

## ساختار

| مسیر | نقش |
| --- | --- |
| `index.html` | پوسته‌ی UI (RTL) |
| `css/app.css` | تم تیره/روشن |
| `js/data.js` | دریافت (مستقیم/پروکسی) + پارسر فید TSETMC |
| `js/filters.js` | ۱۸ فیلتر (ویژه + پایه) |
| `js/sectors.js` | نگاشت کد گروه به نام (از خود سایت) |
| `js/app.js` | رابط کاربری، جدول، مرتب‌سازی، تناوب به‌روزرسانی |
| `js/util.js` | قالب‌بندی اعداد |
| `sw.js` · `manifest.webmanifest` · `icons/` | PWA (نصب روی گوشی/دسکتاپ، کش پوسته) |
| `test/run-tests.mjs` | تست‌های بدون DOM |

## نکته‌ها

- داده‌ی بازار هرگز کش نمی‌شود؛ فقط پوسته‌ی اپ آفلاین می‌ماند.
- کلیک روی نماد، صفحه‌ی آن نماد در سایت TSETMC را در تب جدید باز می‌کند.
- اگر همه‌ی راه‌های دریافت شکست بخورند، اپ فهرست تلاش‌ها را نشان می‌دهد و می‌توانید «داده‌ی نمونه» ببینید.
- این پروژه غیررسمی است و وابسته به TSETMC نیست.
